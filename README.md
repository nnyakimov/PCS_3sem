Design
Первый экран демонстрирует страницу с возможностью начать работу. Нажав на кнопку «Начать», пользователь перейдёт на следующую страницу с самим функционалом. На данной странице использовались такие элементы, как Ellipse, Text, Frame.
На втором экране имеется одна кнопка для добавления заметок. На данной странице использовались такие элементы, как Text, Frame.
На третьем экране расположено поле для ввода заметок. Внизу страницы находятся две кнопки, нажатие на которые выполнит соответствующие действия: «Сохранить» и «Назад». На данной странице использовались такие элементы, как Text, Frame.
